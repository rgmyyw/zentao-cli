ZenTao CLI

命令速查

把任务、Bug、需求、执行、测试、构建、动态和统计能力接到终端、脚本、CI 和 AI Skill。

GitHub npm
一键安装 CLI + Skill
npx -y @cloudglab/zentao-cli@latest install
已安装后更新
zentao update
自举更新
npx -y @cloudglab/zentao-cli@latest update

Wiki / 检索

先做成静态检索：安装、角色、任务、Bug、需求、执行、测试、构建和环境变量都能在本页快速过滤。后续可以扩展为构建期索引，覆盖 README、CHANGELOG 和源码导出的命令清单。

输入关键词后过滤下方命令。

常用场景

  • 今天要做什么zentao getMyTasks --status all --limit 20
  • 我名下 Bugzentao getMyBugs --limit 50
  • 最近三天工作zentao getMyWeeklyActivity --dateRange 最近3天
  • 迭代每日质量报告zentao getExecutionDailyBugStats --executionId 2130 --iterationName 1.2.3迭代
  • 从需求看开发上下文zentao getDevelopmentContext --entityType story --entityId 10154 --productId 153
  • 从 Bug 看关联上下文zentao getDevelopmentContext --entityType bug --entityId 84362

环境变量

  • 服务地址export ZENTAO_URL="https://your-zentao.example.com"
  • 账号export ZENTAO_USERNAME="your-account"
  • 密码export ZENTAO_PASSWORD="your-password"
  • API 版本export ZENTAO_API_VERSION="v1"
  • 自定义 API 地址export ZENTAO_API_BASE_URL="https://your-zentao.example.com/api.php/v1"
  • 禁用写操作export ZENTAO_DISABLE_WRITE=true
写操作默认可用；真实写入仍需显式传入 confirm=true。
