Wiki / 检索

先做成静态检索：安装、角色、任务、Bug、需求、执行、测试、构建和环境变量都能在本页快速过滤。后续可以扩展为构建期索引，覆盖 README、CHANGELOG 和源码导出的命令清单。

输入关键词后过滤下方命令。

基础

  • 一键安装npx -y @cloudglab/zentao-cli@latest install
  • 更新 CLIzentao update
  • 查看版本zentao version
  • 列出命令zentao list
  • 查看参数zentao help getExecutionDetail
  • 查看当前用户zentao whoami

我的工作

  • 我的任务zentao getMyTasks --status all --limit 20
  • 我的 Bugzentao getMyBugs --limit 50
  • 任务统计zentao getMyTaskStatistics
  • 最近工作zentao getMyWeeklyActivity --dateRange 最近3天

角色入口

  • 完整能力zentao --role full list
  • 研发常用zentao-dev getMyTasks --limit 20
  • 测试常用zentao-qa getMyBugs --limit 50
  • 产品项目zentao-pm getProducts

执行 / 迭代

  • 执行详情zentao getExecutionDetail --executionId 2130
  • 执行 Bugzentao getExecutionBugs --executionId 2130 --limit 100
  • 执行构建zentao getExecutionBuilds --executionId 2130
  • 项目发布zentao getProjectReleases --projectId 1772
  • 发布详情zentao getReleaseDetail --releaseId 1
  • 每日统计zentao getExecutionDailyBugStats --executionId 2130

产品 / 需求

  • 产品列表zentao getProducts
  • 需求详情zentao getStoryDetail --storyId 10154
  • 搜索需求zentao searchStories --keyword 登录
  • 计划详情zentao getPlanDetail --planId 360

环境变量

  • 服务地址export ZENTAO_URL="https://your-zentao.example.com"
  • 账号export ZENTAO_USERNAME="your-account"
  • 密码export ZENTAO_PASSWORD="your-password"
  • API 版本export ZENTAO_API_VERSION="v1"
写操作默认可用；真实写入仍需显式传入 confirm=true。
