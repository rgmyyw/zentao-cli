# 总览

## 这个 skill 做什么

- 用命令行方式操作禅道
- 默认只 preview，不直接写线上
- 支持任务、Bug、需求、项目、执行、构建、测试用例、测试单等常用场景

## 推荐工作流

1. 先确认本机是否安装 `zentao`
2. 如果没有，优先安装或升级本地 `zentao`
3. 先判断用户问的是普通禅道产品数据，还是业务产品的线上 / 客户反馈 / 生产问题
4. 如果是线上 Bug，按 `reference/bug.md` 先判断来源：市场 / 售后 / 客户反馈查 `市场和售后问题跟踪`，测试 / 开发自发现查 `测试`，再用模块匹配真实业务产品
5. 根据问题类型，先看 `reference/commands.md` 的查询命令速查，再去对应专题 reference 文档确认细节
6. 对命令参数不确定时，先运行 `zentao help <command>` 校对，不要猜参数
7. 默认只 preview；写操作必须显式确认

补充：当前发布产物运行时目标为 `Node.js >= 16`；开发 / 构建环境可以更高。

## 适合谁

- 需要命令行操作禅道的人
- 需要把禅道接入智能体的人
- 需要在旧版本禅道环境下稳定使用的人
